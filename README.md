# Keeplight

Plan artifact: https://claude.ai/artifact/PisWk9vuT3sDiHuyRxWktu

Keeplight shows every light in the PC, lets you set each one with a click, and puts your colors back on its own after a restart, a sleep or a power cut. It runs on top of [OpenRGB](https://openrgb.org), which does all the hardware work.

Early development. The app follows in pull requests.
